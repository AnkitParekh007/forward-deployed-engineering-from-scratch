# Success metrics and pilot

## Why this matters
A support assistant proposes categories.

## Learning objectives
- Explain success metrics and pilot in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## Prerequisites
Complete lesson 04-04: Scope and prioritization; use synthetic data.

## Concepts
Define success, guardrails, sample and decision rule before starting a pilot.

## Build it
1. Read the scenario and identify the input and expected output.
2. Set a target accuracy, manual review rate and a pilot stop rule.
3. Verify the result using the success evidence below.

## Real-world scenario
A support assistant proposes categories. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## Checkpoint
1. Why include a stop rule?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## Deliverable
A pilot scorecard with denominators.
