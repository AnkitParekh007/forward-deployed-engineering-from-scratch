# Python essentials

## 💡 Why this matters
A support queue needs counts by category.

## 🎯 Learning objectives
- Explain python essentials in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## 🧰 Prerequisites
Complete lesson 02-01: Files, terminals and Git; use synthetic data.

## 🧠 Concepts
Variables hold values; functions transform inputs into outputs. Lists and dictionaries represent business records.

## 🛠️ Build it
1. Read the scenario and identify the input and expected output.
2. Write a function counting synthetic ticket categories, including an empty list.
3. Verify the result using the success evidence below.

## 🌐 Real-world scenario
A support queue needs counts by category. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## ⚠️ Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## 🧪 Checkpoint
1. Why use functions?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## 📦 Deliverable
A count dictionary and two passing assertions.
