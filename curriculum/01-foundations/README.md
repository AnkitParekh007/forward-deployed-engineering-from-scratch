## 🌐 Real FDE scenario

## ✅ Success criteria
- A Git log containing one meaningful commit.
- A count dictionary and two passing assertions.
- Invalid records are rejected with a clear message.
- Mean 21.4 and median 5.
- A 200 response and parsed record.
