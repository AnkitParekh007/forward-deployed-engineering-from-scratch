## Mini-project

## Real FDE scenario
A ticket classifier confuses priority and sentiment.

## Success criteria
- Outputs and error categories.
- Valid response accepted, malformed response rejected.
- The first pair ranks above the orthogonal pair.
- Retrieval results and one abstention case.
- Precision 0.8 and recall 0.667.
