# Model selection tradeoffs

## 💡 Why this matters
A retailer needs fast category suggestions.

## 🎯 Learning objectives
- Explain model selection tradeoffs in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## 🧰 Prerequisites
Complete lesson 05-02: How language models work; use synthetic data.

## 🧠 Concepts
Compare quality, latency, privacy and price using the same representative tasks. Bigger is not always better.

## 🛠️ Build it
1. Read the scenario and identify the input and expected output.
2. Make a weighted comparison of two hypothetical models using labeled sample measurements.
3. Verify the result using the success evidence below.

## 🌐 Real-world scenario
A retailer needs fast category suggestions. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## ⚠️ Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## 🧪 Checkpoint
1. Why compare the same test set?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## 📦 Deliverable
A transparent decision matrix.
