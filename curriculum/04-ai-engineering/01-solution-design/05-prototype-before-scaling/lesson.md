# Prototype before scaling

## Why this matters
A product lead needs themes from 20 comments.

## Learning objectives
- Explain prototype before scaling in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## Prerequisites
Complete lesson 05-04: Design the AI application; use synthetic data.

## Concepts
Use synthetic data and a deterministic baseline before introducing optional model calls. Validate a single task first.

## Build it
1. Read the scenario and identify the input and expected output.
2. Group a synthetic sample using keywords and label borderline cases.
3. Verify the result using the success evidence below.

## Real-world scenario
A product lead needs themes from 20 comments. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## Checkpoint
1. What should a prototype prove?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## Deliverable
A baseline output and review notes.
