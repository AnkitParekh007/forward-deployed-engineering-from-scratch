# When to use AI

## Why this matters
A finance team routes invoice records.

## Learning objectives
- Explain when to use ai in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## Prerequisites
Complete lesson 04-05: Success metrics and pilot; use synthetic data.

## Concepts
Rules work well with stable exact logic; ML is useful for patterns; LLMs can handle unstructured language but may err.

## Build it
1. Read the scenario and identify the input and expected output.
2. Compare a deterministic rule with an LLM for two fields and justify the choice.
3. Verify the result using the success evidence below.

## Real-world scenario
A finance team routes invoice records. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## Checkpoint
1. Should an LLM calculate exact totals?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## Deliverable
A baseline comparison table.
