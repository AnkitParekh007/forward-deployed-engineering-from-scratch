# AI-assisted learning

## 💡 Why this matters
A graduate inherits a generated prototype.

## 🎯 Learning objectives
- Explain ai-assisted learning in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## 🧰 Prerequisites
Complete lesson 01-03: The smallest useful slice; use synthetic data.

## 🧠 Concepts
A coding assistant can draft code, but the learner must explain and verify each change. Provide explicit requirements and observable acceptance tests.

## 🛠️ Build it
1. Read the scenario and identify the input and expected output.
2. Ask an assistant for a simple transformation function, then manually test empty, valid and malformed inputs.
3. Verify the result using the success evidence below.

## 🌐 Real-world scenario
A graduate inherits a generated prototype. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## ⚠️ Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## 🧪 Checkpoint
1. Who owns verification?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## 📦 Deliverable
Three recorded input-output checks.
