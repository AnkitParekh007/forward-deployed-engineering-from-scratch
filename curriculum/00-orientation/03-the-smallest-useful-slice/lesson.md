# The smallest useful slice

## Why this matters
An onboarding team wants a complete AI platform.

## Learning objectives
- Explain the smallest useful slice in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## Prerequisites
Complete lesson 01-02: Start with outcomes; use synthetic data.

## Concepts
An end-to-end slice solves one narrow workflow with a real input and output; it is easier to validate than a large feature list.

## Build it
1. Read the scenario and identify the input and expected output.
2. Sketch a one-screen prototype that extracts onboarding requirements only.
3. Verify the result using the success evidence below.

## Real-world scenario
An onboarding team wants a complete AI platform. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## Checkpoint
1. Why prefer a thin slice?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## Deliverable
A clear in-scope and out-of-scope list.
