## Real FDE scenario

## Success criteria
- A before/after data inventory.
- Denied cross-account access test.
- An example config with placeholders only.
- A regression test and review outcome.
- A documented go/no-go review.

## Phase quiz
- Why minimize data?
- What is least privilege?
- Can a Vite public env variable contain a secret?
- Should retrieved text set system permissions?
- Who decides acceptable residual risk?
