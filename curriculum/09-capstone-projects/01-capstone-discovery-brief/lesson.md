# Capstone discovery brief

## Why this matters
A fictional manufacturer needs onboarding assistance.

## Learning objectives
- Explain capstone discovery brief in your own words.
- Apply the concept to the customer scenario.
- Produce and independently verify the requested evidence.

## Prerequisites
Complete lesson 11-05: Handoff and customer onboarding; use synthetic data.

## Concepts
Start with one synthetic customer, one problem, baseline and acceptance criteria. Make unsupported assumptions explicit.

## Build it
1. Read the scenario and identify the input and expected output.
2. Choose a project, write a brief and define minimum scope.
3. Verify the result using the success evidence below.

## Real-world scenario
A fictional manufacturer needs onboarding assistance. An FDE documents assumptions, tests the smallest useful change and reviews the outcome with the workflow owner.

## Common mistakes
- Treating a generated result as verified evidence. Check it independently.
- Using real customer data in a learning demo. Use synthetic records.
- Hiding missing evidence. Document limitations and ask for review.

## Checkpoint
1. What is the capstone scope boundary?
2. What evidence would show your exercise works?
3. What should you do if the evidence fails?

## Deliverable
A signed-off simulated brief and measurable tests.
