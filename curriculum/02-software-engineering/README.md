## Mini-project

## Real FDE scenario
An operator needs a ticket queue.

## Success criteria
- A usable keyboard-accessible screen.
- A valid request and a rejected invalid request.
- A reproducible query and result.
- Tests fail before the fix and pass after it.
- A workflow and passing test log.
