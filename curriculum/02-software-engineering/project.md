# Mini-project: Customer issue triage

Use the five lesson deliverables in this phase. Combine them into a single README with a customer brief, steps, evidence, limitations, and next decision.

## Acceptance
- A usable keyboard-accessible screen.
- A valid request and a rejected invalid request.
- A reproducible query and result.
- Tests fail before the fix and pass after it.
- A workflow and passing test log.
